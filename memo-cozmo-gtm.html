Cozmo / GTM engineering

The prospect's own workflow is the only demo that matters.

Avi Bedi / November 16, 2026 / Outside-in analysis

My read: Cozmo already knows its best sales asset - a working agent pointed at the prospect's own problem - and the GTM job is to mass-produce that moment.

What I noticed

Cozmo (YC) puts AI on the contractor's phone at the first hours after a property loss: intake, job logging, a line-item estimate from photos, and a claim filed with the carrier before an adjuster is scheduled. The numbers behind it are serious - 1M+ calls in production, Allianz as an early insurance partner, two of the top five US restoration franchises onboarding - in an industry that pays $650B in claims a year and loses $120B to fraud. Its GTM Engineer internship (San Francisco, posted about a month ago) asks one person to build the agent stack that runs the company's own top of funnel and to stand up custom proof-of-concept agents for live deals in days.

I'd test a PoC-factory motion: pick the two or three contractor workflows that recur across deals, templatize each into a demo agent that can be pointed at a new prospect's data within a day, and measure which template shortens the path to a signed pilot. The internship description says no slide deck stands in for watching your own workflow run - so the system that produces those moments fastest is the growth engine. That is a sales-process hypothesis, not a claim that Cozmo's current deal cycle is slow.

What I'd do in my first 30 days

Days 1-7. Learn the product and the claim lifecycle end to end, shadow live deals, and catalog the prospect workflows that keep repeating.

Days 8-20. Build the first reusable PoC template on one recurring workflow, wire it into the prospecting stack, and run it against a real account.

Days 21-30. Measure meetings and pilot conversions from templated PoCs versus custom builds, document the build process, and spec the next two templates.

I build agent tooling myself and I have run outbound, so a role that asks one person to both ship the code and read the deal is close to my ideal internship description. The insurance claims domain is new to me, which makes the discovery half of the job genuinely interesting.
