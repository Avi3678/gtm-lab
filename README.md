# Avi Bedi / GTM Lab

29 independent browser prototypes for growth, content, business development and operations.

## Run

Unzip the project, then open `index.html` in a modern desktop browser. Each project is a standalone HTML file with its own CSS and JavaScript. No package install, build command, account, API key or backend is needed. A static web server also works. Clipboard copying can be restricted by browser/device policy; select and copy the output manually if needed. External source links require internet access. Mobile file previews may not execute JavaScript: use a full browser or a static-hosted URL.

## What works

Each page includes its local calculations, filters, input validation, workflow state or deterministic draft templates. Data is session-only and resets on reload. Nothing is saved to a shared database. No analytics or external script dependencies are included.

## Boundaries

- These are not the named companies' products and are not affiliated with or endorsed by them.
- Fictional fixtures and assumptions are marked. No campaign performance is fabricated.
- Public facts are attributed and linked. Fixed-vintage data is not advertised as latest data.
- No live AI, web crawling, production telemetry, third-party account integrations, outbound messaging, payments or trades.
- Templates and rule-based checks do not certify truth, legal approval, product quality or safety.
- Review each project and its limitations before external use. Never paste private data, credentials or real customer information into a public demo.
